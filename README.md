## Selected projects

### [GMAHK Galilea](https://github.com/zvenians/gmahk-galilea)
Website for the Galilea congregation, with worship schedules, news, Bible and hymn readers, and presentation tools. Uses JavaScript, Vercel functions, Google Apps Script, and Google Sheets.

[Visit website](https://gmahk-galilea.vercel.app/)

### [Galilea Digital Archive](https://github.com/zvenians/gmahk-galilea-digital-archive)
A media and document archive built with Next.js, TypeScript, Firebase, and Google Drive. The project includes upload workflows, archive browsing, and administrative controls.

[Visit archive](https://drive-galilea.vercel.app/)

### [Majelis Galilea](https://github.com/zvenians/majelis-galilea)
Administration tools for church meetings, decisions, programs, financial records, and correspondence. Built with Google Apps Script, Google Sheets, and a Vercel API proxy.

[Visit portal](https://majelis-galilea.vercel.app/)

### [Kevin's Portfolio](https://github.com/zvenians/kevins-portofolio)
A personal portfolio with interactive presentations and project demonstrations. The public presentation is maintained in `apps-script/source/` and served from `vercel-site/`.

[View portfolio](https://portfolio-kevins.vercel.app)

### [Naomi Rouli](https://github.com/zvenians/naomirouli)
A small editorial website featuring photography, chapter-based navigation, and a responsive gallery. Built with HTML, CSS, JavaScript, and Firebase Hosting.

[View website](https://naomirouli.web.app)
